# employee-tracker
Commnd-line application to track employees
## Description

The purpose of this project is to create a command-line application that tracks employees' titles and salaries at a company. The application prompts the user to add an employee, role, salary, and the specified deparment. After going through the creation process or the selection process, the user is able to perform certain actions. The user is returned to the actions menu after each action until they decide to exit the application.

## Installation

To install necessary dependencies and build the application, run the following commands:

```
npm i
npm run build
```

## Usage

Install dependencies, run the generator in an integrated terminal, follow the prompts, check and preview your employee tracker.
